# insta-terra-gentil

Máquina de conteúdo do Instagram da Terra Gentil (@canalterragentil): um post por dia, aprovado
pelo André uma vez por semana no Telegram.

- Especificação: https://claude.ai/artifact/Hj1ysfH7HQFmeggS4h5i7r
- Regras para quem mexe no código (pessoa ou IA): `AGENTS.md`
- Testes: `npm --prefix insta-terra-gentil test` (da raiz do repositório)

|---|---|
| Segunda | Carrossel: Socorro |

| Quarta | Carrossel: Mito ou verdade |

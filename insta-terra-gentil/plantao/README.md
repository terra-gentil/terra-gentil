# plantao: reel do André

**Fase 4.** O André grava no celular tratando uma planta doente e manda o bruto. A máquina:
transcreve, corta silêncio e erro, faz legenda palavra por palavra, encaixa b-roll do acervo
casado com a fala e monta as cenas no HyperFrames. Prévia no Telegram; sem ok, não sai.

Começa como prova de conceito (HyperFrames está na versão 0.4).
Previstos: `transcrever.mjs`, `cortes.mjs`, `legenda.mjs`, `broll.mjs`, `cenas/` (HTML do
HyperFrames), `render.mjs`.

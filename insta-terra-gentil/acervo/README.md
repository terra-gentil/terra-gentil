# acervo: trechos de b-roll

**Fase 3.** Trechos de 2 a 6 s no Cloudflare R2 (bucket `terragentil-midia`), escolhidos por
etiqueta. Meta: 100, depois 300, depois 700.

Ficha de cada trecho: `especie`, `acao`, `clima`, `origem`, `licenca`, `autor`, `link`, `som`,
`dur`, `descricao`. Planta certa: cena da espécie só com a etiqueta exata; sem ela, ilustração.

Fontes: vídeos do canal, Google Flow, bancos gratuitos (Pexels, Pixabay, Mixkit, Coverr).
Previstos: `etiquetas.mjs`, `escolher.mjs` (rodízio sem repetir), `r2.mjs`, `buscar-bancos.mjs`.
